CORE + PRIVATE MARKETS

CFA 三级学习页

输入此学习页专用的 GitHub 令牌，即可读取私人学习资料和跨设备进度。

首次设置
  1. 在 GitHub 创建细粒度访问令牌。资源所有者选择自己的账号。
  2. 仓库访问选择 Only select repositories，只勾选 cfa-l3-study-private。仓库权限 Contents 设为 Read and write，其余维持默认。
  3. 将令牌填入本页。另一台设备打开同一个网址并输入专用令牌后，可读取进度。每台设备也可以用自己的专用令牌。
令牌只发送到 GitHub API。记住令牌会保存在当前浏览器，同一 GitHub Pages 域名下的页面共享浏览器存储范围。
